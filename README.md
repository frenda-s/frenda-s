### About

High school student at Nguyen Chi Thanh High School for the Gifted, building web applications end to end. My main stack is Vue 3, Nuxt, and Hono running on Cloudflare Workers, with Turso/libSQL and Drizzle for persistence. I also write Python for automation and tooling, C++ for algorithmic work, and I spend most of my time on CachyOS.

Currently most active in: [qlynenep](https://github.com/frenda-s/qlynenep), [spotify-downloader](https://github.com/frenda-s/spotify-downloader), [frdb](https://github.com/frenda-s/frdb).
